# web

Next.js (App Router) + TypeScript front end, built as a static export (`npm run build` writes `out/`).

```
src/app/          layout, page and globals.css (tokens from spec 10, layouts from spec 4)
src/components/   Dashboard, RiskCard, StatTiles, WeekChart, DayStrip, EventsList, SiteCard,
                  IslandStage, ModeSwitch, Mascot
src/scene/        three.js island (IslandScene), clay model helpers, layout breakpoints
src/i18n/         en.json (default), pap.json (falls back to English per key)
src/lib/          data contracts (schema.ts), levels, time (America/Curacao), mode, data loading
public/data/      forecast.json and events.json (example data for now; the pipeline replaces them)
public/mode-init.js  sets day/night before first paint
```

Scripts: `npm run dev`, `npm run build`, `npm run lint`, `npm run typecheck`.

`AGENTS.md` is generated by Next.js and points coding agents at the docs bundled with this Next.js version.
