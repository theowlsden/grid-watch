# web

Next.js (App Router) + TypeScript front end, built as a static export (`npm run build` writes `out/`).

```
src/app/          layout, page and globals.css (tokens from spec 10, layouts from spec 4)
src/components/   Dashboard, RiskCard, StatTiles, WeekChart, DayStrip, EventsList, SiteCard,
                  IslandStage, ModeSwitch, Mascot
src/scene/        three.js island (IslandScene), clay model helpers, layout breakpoints
src/i18n/         en.json (default), pap.json (falls back to English per key)
src/lib/          data contracts (schema.ts), levels, time (America/Curacao), mode, data loading
public/data/      forecast.json and events.json (example data for now; the pipeline replaces them)
public/mode-init.js  sets day/night before first paint
```

Scripts: `npm run dev`, `npm run build`, `npm run lint`, `npm run typecheck`, `npm run licenses`.

## Tests

End-to-end tests (Playwright, spec 11) run against the static export served by `tests/serve.mjs`:

```sh
npx playwright install chromium   # once
npm run test:e2e                  # build, then run every test
npm run test:e2e:only             # run against the current build
npx playwright show-report        # screenshots of every layout are attached to the report
```

`tests/e2e/`: layouts and no-overlay checks at every size in day and night, site cards and tapping,
day picker, day/night mode with a mocked clock, no-WebGL fallback, data states (example tag, load
failure, events), scene contents (no sun, solar or battery), and axe accessibility scans.
The scene exposes a read-only test hook (`window.__gridWatch`) only when the browser is automated.

`AGENTS.md` is generated by Next.js and points coding agents at the docs bundled with this Next.js version.
