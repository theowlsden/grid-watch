# Contributing

Thanks for your interest in Grid Watch Curaçao.

- **Issues are welcome**: bugs, unclear wording, accessibility problems, and corrections to the event database.
- **Data corrections need a public source.** Use the "Data correction" issue template and link the report, article or document. Unsourced claims about the utility are not accepted.
- **Discuss before large pull requests.** Open an issue first so we can agree on the approach. Small fixes can go straight to a PR.
- **Keep the framing.** The project estimates supply stress from public data. It does not predict blackouts or utility decisions. Copy, code comments and docs must follow the wording rules in [docs/SPEC.md](docs/SPEC.md) section 1.
- **No secrets, no personal data.** Never commit tokens, passwords, `.env` files, Telegram IDs or personal details. CI runs a secret scanner and will fail on findings; you can run it locally with `pre-commit install`.
- **Papiamentu copy** is reviewed by a native speaker before it ships. Suggestions are welcome as issues or PRs.
